1️- Difference between getElementById, getElementsByClassName, querySelector, querySelectorAll

getElementById() → Selects one element by id.

getElementsByClassName() → Selects multiple elements by class name.

querySelector() → Selects the first matching element using CSS selector.

querySelectorAll() → Selects all matching elements using CSS selector.

2️- How do you create and insert a new element into the DOM?

We create a new element using createElement() and insert it parentnode using append() or appendChild().

3️- What is Event Bubbling?

Event Bubbling is a process where an event starts from the target element and moves up to its parent elements.

4️- What is Event Delegation? Why is it useful?

Event Delegation is a technique where we add an event listener to a parent element instead of multiple child elements.
It is useful for better performance and handling dynamic elements.

5️- Difference between preventDefault() and stopPropagation()

preventDefault() → Stops the default browser action.

stopPropagation() → Stops the event from moving to parent elements.
